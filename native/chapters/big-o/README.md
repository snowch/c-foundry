# Chapter 11: Correctness and Big O

Part 3: Learn to reason about algorithms

This is a chapter workspace and syllabus stub. Full instruction and graded exercises are planned.

## Planned topics

1. Input size and counting work
2. O, Θ, and Ω notation
3. Constant, logarithmic, linear, linearithmic, and quadratic growth
4. Best, average, and worst cases
5. Time, auxiliary space, and amortized analysis
6. Loop invariants and correctness arguments
7. Predict growth before measuring it

## Practice goal

Compare counted search operations, then explain how doubling the input changes the work.

## Execution

The planned core exercises fit the browser C runtime. Codespaces is optional. All explanations and previews remain readable in the web course.

From the repository root:

```sh
make chapter CHAPTER=big-o
```
