# Chapter 10: Files, bytes, and reliable C

Part 2: Understand memory and practical C

This is a chapter workspace and syllabus stub. Full instruction and graded exercises are planned.

## Planned topics

1. Text and binary file I/O
2. Fixed-width integers, bitwise operations, and masks
3. Endianness and explicit serialization
4. Undefined behavior, assertions, and debugging
5. Testing, sanitizers, portability, and browser runtime limits
6. A portable binary record format

## Practice goal

Write and read a documented binary format without dumping raw structs.

## Execution

Multi-file builds, native diagnostics, or compiler features need the Linux toolchain. All explanations and previews remain readable in the web course.

From the repository root:

```sh
make chapter CHAPTER=files-bytes
```
